# Change Log

Todas las modificaciones importantes de la extensión **SnipX** serán documentadas en este archivo.

Este proyecto sigue las recomendaciones de [Keep a Changelog](https://keepachangelog.com/).

---

## [0.0.1] - 2026-01-01

### ✨ **Lanzamiento Inicial**

¡Hola! Esta es la primera versión pública de **SnipX**, una extensión de Visual Studio Code con una colección de snippets profesionales listos para usar, diseñados para acelerar significativamente el desarrollo web en HTML y CSS.

### 📦 Added

#### Snippets de Componentes HTML

- `hdr` - Componente Header con Navegación (nav bar responsiva)
- `formc` - Formulario de Contacto Básico (con campos estándar)
- `formp` - Formulario Profesional Simple (layout limpio)
- `formr` - Formulario de Registro Profesional Compacto (con validación básica)
- `testimonio` - Sección de Testimonios (grid responsivo con 3 items)
- `footerb` - Footer Básico con Copyright (minimalista)
- `footerc` - Footer Elaborado Completo (con 3 secciones y enlaces)
- `modal` - Modal Simple usando Popover API (confirmación)
- `modalf` - Modal Informativo usando Popover API (con icono)
- `layout` - Layout Web Simple (Header + Main + Footer con Flexbox)
- `layoutc` - Layout Web Moderno Completo (Header + Nav + Grid + Aside + Footer)
- `cards` - 3 Tarjetas Básicas (card containers responsivas)
- `hero` - Header Hero Completo Full Screen (banner con navegación)
- `selectp` - Selector con Opciones Personalizable (custom select)
- `search` - Buscador Profesional Simple (search bar funcional)

#### Snippets de Animaciones y Efectos CSS

- `btn-li` - Botón con Efecto Líquido (gradiente animado al hover)
- `typewriter` - Máquina de Escribir (efecto de escritura progresiva con cursor)
- `btn-neon` - Botón Neón Multicolor (glow effect al hover)
- `btn-loa` - Botón de Carga (transformación a spinner circular)
- `card-3d` - Tarjeta Flip 3D (volteo con dos caras)
- `3d-animation` - Tarjeta Tilt 3D (rotación según posición del cursor)
- `icons` - Iconos Magnéticos 3D (efecto de atracción al cursor)

### 🎯 Características Generales

- ✅ **Prefixes cortos y fáciles de recordar** - Acceso rápido a todos los snippets
- ✅ **Código limpio y profesional** - Listo para producción o personalización
- ✅ **Estilos CSS integrados** - Incluidos en comentarios dentro de cada snippet
- ✅ **Sin dependencias externas** - Funciona con CSS puro y HTML semántico
- ✅ **Responsive Design** - La mayoría de componentes incluyen soporte mobile
- ✅ **Documentación clara** - Cada snippet tiene descripción detallada en VS Code

### 📋 Requisitos

- Visual Studio Code 1.107.0 o superior
- Sin dependencias externas necesarias

### 📝 Notas

- Todos los snippets son completamente personalizables
- Los archivos de snippet se encuentran en `snippets/`
- HTML snippets → `snippets/snippets.code-snippets`
- CSS snippets → `snippets/css-snippets.code-snippets`
